Quick examples

Strength labels use a common classroom guide: |r| ≥ 0.8 strong, 0.5–0.8 moderate, 0.3–0.5 weak, below 0.3 little or none. Try a steep line and a gentle line with the same scatter: the steepness barely changes r, but the scatter does.
